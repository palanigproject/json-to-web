Quick Actions

  • Build: Generate web application from JSON configuration

  • Configure: Edit JSON files in the config/ directory

Configuration Files

  • config/front-end.json - Frontend page structure
  • config/back-end.json - Backend API configuration
  • config/database.json - Database settings
  • config/models.json - Data models
  • config/pages/ - Individual page configurations
